# Gozareshgir Desktop (ناچ دسکتاپ گزارش‌گیر)

اپلیکیشن مستقل دسکتاپ نیتیو برای سیستم‌عامل‌های مک (macOS) و ویندوز (Windows) جهت رصد آنی تسک‌های برد اجرایی گزارش‌گیر به سبک **Dynamic Island / Notch** و منوبار سیستم.

---

## ویژگی‌ها

- 🏝️ **طراحی Dynamic Island زیر ناچ مک‌بوک:** ویجت کپسولی مشکی که دقیقاً زیر بریدگی ناچ صفحه قرار می‌گیرد و بدون ایجاد مزاحمت، تسک فعال را نشان می‌دهد.
- ⏱️ **شمارنده زنده زمان (Live Timer):** نمایش زنده زمان باقی‌مانده و صرف‌شده و درصد پیشرفت کار.
- 📋 **تفکیک سه وضعیت تسک‌ها:**
  - **در حال انجام (In Progress):** تسک اکتیو با کارت برجسته، مسیر کامل پروژه، درصد پیشرفت و نام مجری.
  - **متوقف شده (Stopped):** تسک‌های هولد شده به همراه زمان باقی‌مانده.
  - **برای انجام (Todo):** تسک‌های در صف بر اساس اولویت.
- 🔄 **به‌روزرسانی خودکار:** پولینگ خودکار هر ۱۰ ثانیه از `https://dadmehrg.ir/api/ProgramManager/ExecuteBoard` به همراه دکمه رفرش دستی.
- 🔐 **احراز هویت درون‌برنامه‌ای:** فرم ورود نام کاربری و رمز عبور با ذخیره امن توکن و تمدید خودکار توکن (Refresh Token Interceptor).
- 🍎 **یکپارچگی با منوبار مک (System Tray):** آیکون در Status Bar بالای مک جهت نمایش/پنهان‌سازی سریع و خروج از برنامه.

---

## پیش‌نیازها

- Node.js (نسخه 18 یا بالاتر) و pnpm
- ابزار Rust (`rustc` و `cargo`) که از طریق `rustup` نصب شده است.

---

## دستورات اجرایی

### اجرای حالت توسعه (Development)
```bash
# بارگذاری متغیرهای محیطی Rust (در صورت نیاز)
source $HOME/.cargo/env

# اجرای برنامه در حالت توسعه با Hot Reload
pnpm tauri dev
```

### بیلد نهایی و ساخت پکیج نصبی (Production Build)
```bash
source $HOME/.cargo/env

# ساخت فایل اجرایی و پکیج نصبی (.dmg یا .app در مک و .msi/.exe در ویندوز)
pnpm tauri build
```

فایل‌های خروجی در مسیر زیر قرار می‌گیرند:
`src-tauri/target/release/bundle/`
